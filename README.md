# When Stars Fell

A fully playable browser-based 3D story-mode prototype built with **HTML/CSS/JavaScript + Three.js**.

## Run
Use any static file server from the repo root:

```bash
python3 -m http.server 4173
```

Then open:

- `http://localhost:4173`

## Controls
- **Desktop**: WASD / Arrow keys to move, hold left mouse button and drag to look, **E** or click to interact.
- **Mobile**: virtual joystick (left), **E** button (right) to interact.

## Features Included
- 7 playable chapters in sequence.
- Third-person 3D explorable world with strong Undercity/Uppercity contrast.
- 30+ visible NPCs with simple ambient movement routines.
- Interaction system and objective HUD.
- Functional mini-games:
  - Window/open-day start interaction
  - Alien drawing mini-game
  - Shop toy organizing mini-game
- Chapter-tied lighting/palette shifts (morning → night).
- Dramatic alien crash finale with impact flash and screen shake.
- Memory Sketch collectible system + gallery panel.
- Responsive layout with mobile controls.
